Image Metadata Cleaner

Remove EXIF, XMP and C2PA provenance metadata from JPEG, PNG and WebP images. Everything runs in this page - your image never leaves your device.

Drop an image here or click to choose one JPEG, PNG or WebP. Pixels are copied byte-for-byte; only metadata containers are removed.

What this does not do: invisible watermarks embedded in the pixels themselves (such as SynthID, which OpenAI states is embedded in ChatGPT-generated images) are part of the image data and are not removed. Removing them is not possible without altering pixels. See the project README for sources.
